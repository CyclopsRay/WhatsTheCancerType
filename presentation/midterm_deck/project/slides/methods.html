Optimal transport and any new marker-selection model are optional extensions, attempted only after this core is complete.

This addresses the feasibility concern directly. Each step is a standard method with a known statistical model. The replication unit is the donor throughout. Cells are summed to one pseudobulk profile per specimen, and DESeq2 compares each polyp to its own donor’s normal tissue. Optimal transport, which was in our roadmap, is now optional, because the published lesion-state labels already answer the first-order question of whether polyps contain new states.
